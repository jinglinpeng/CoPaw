产品手记

QwenPaw 接入 Jev 决策模型

QwenPaw 现已支持 TypeSafe 的决策模型 Jev。执行工具前，QwenPaw 可以调用 Jev 评估风险，决定是否需要用户确认。对话过长时，Jev 还可以判断哪些工具输出与当前任务有关，供 QwenPaw 压缩对话时参考。

工具审批和对话压缩可以单独开启。配置 Jev 后，仍由原来的聊天模型与用户对话、执行任务。

01工具审批

一次批准只对当次操作有效

以修改行程单为例。用户同意助手新建一份文件，写下“周六下午去博物馆”。后来行程有变，要把博物馆改成公园。这一次，助手要改写已有文件，上次的批准不会自动生效。

如果 Jev 判断此次写入可能覆盖已有内容，QwenPaw 会显示审批卡。用户可以拒绝这次修改，让助手把新行程另存一份。

工具执行前的风险评估

QwenPaw 先检查本地规则，拦截明确禁止的操作。规则要求审批的操作仍由用户确认。对于需要进一步评估的调用，Jev 从以下四个方面判断风险。

判断维度具体内容
操作影响属于只读操作、常规变更、高风险操作，还是信息不足
数据破坏是否可能删除或覆盖已有用户数据
敏感信息暴露是否可能读取凭据，或将敏感信息传到本机之外
权限变化是否可能扩大权限或削弱安全边界

在本地规则允许的范围内，风险低且判断明确的调用可以继续执行。如果存在风险、评估结果不确定，或决策服务未响应，QwenPaw 会请求用户确认。

02长对话压缩

压缩长对话时，保留与任务有关的原文

一份行程摘要里可能只写了“已订回程车票”。要回答“周日几点发车”，助手需要的是票面上的“18:40”。此前查过的酒店早餐时间，即便占了很长一段记录，此时也用不上。

对话达到自动压缩阈值后，Jev 根据当前任务评估较早的工具输出。对于相关性较低的内容，QwenPaw 可以用简短预览替换全文，同时保留指向原文的引用。在归档保留期内，助手仍可查阅原文。当前这轮对话和近期消息不参与这一步筛选。

缩短工具输出后，如果输入长度已降到阈值以内，QwenPaw 就沿用原有摘要。超过阈值时，再生成新的摘要。 查看验证记录

补入相关原文对关键词正确率的影响

我们用 14 个模拟任务比较了不同输入对回答的影响，共评测 1,092 次回答。每个任务使用同一份历史摘要，分别测试只提供摘要和额外提供若干段原文的情况。补入的原文由 Jev 按任务挑选，评测指标是回答中的关键词是否正确。

在这组实验中，只提供摘要时，关键词正确率为 82.0%。补入三段原文后，正确率为 99.5%。实际运行时，系统按相关性筛选工具输出，保留的段数并不固定。

03上手试用

在 QwenPaw 中启用 Jev

以下设置适用于使用 QwenPaw 原生后端的智能体。先配置决策模型，再选择需要开启的功能。

配置决策模型

在「设置 → 模型」中找到 TypeSafe，填入 API Key 并保存。进入「默认模型 → 决策模型」，选择 Jev Latest（jev-latest）。 获取 API Key

开启工具审批

点击聊天输入栏中的模型名称，展开「高级选项」，打开「使用决策模型」。回到输入栏，在「工具审批模式」中选择「决策模型模式」。评估风险时，工具名称、命令或路径可能会发送至 TypeSafe。使用代码模式时，发送的内容还可能包括已通过本地预检的完整 Python 脚本。

请新建一份“周末行程草稿.txt”，写上“周六下午去博物馆”。

文件创建后，再发送第二条消息。

请把这份草稿里的“去博物馆”改成“去公园”，存回原文件。

如果出现审批卡，可展开查看原因。点击“拒绝”后打开文件，检查其中是否仍为“周六下午去博物馆”。

开启长对话压缩

进入「智能体 → 配置 → 上下文管理」，打开「启用上下文压缩」，再打开「决策模型压缩」并保存。长对话达到自动压缩阈值时，QwenPaw 会把部分对话和工具结果摘录发给 TypeSafe，由 Jev 判断它们与当前任务的相关性。 上下文管理文档

试用时，可以准备一份车票样例，写明“周日 18:40 发车，检票口 8B”，请助手读取。待对话触发自动压缩后，再询问发车时间和检票口，核对回答是否与票面一致。

04本地预览

Piccolo 本地决策模型预览

对于内部代码、客户日志等资料，有些团队要求在本机完成处理。QwenPaw 正在探索本地决策模型 Piccolo。在这套设计中，QwenPaw-Flash 负责规划和执行任务，Piccolo 在本机评估工具风险和历史工具输出的相关性。
