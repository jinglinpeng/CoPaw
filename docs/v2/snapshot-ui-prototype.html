ℹ️
此页面展示导入快照后 Agent 可能出现的三种状态。状态标签显示在侧边栏 Agent 选择器和 Agent 管理页面中。
🟢
就绪 ready
所有组件已激活并正常运行。Agent 完全可用。
🟡
待审核 needs_review
Agent 可对话，但部分组件（技能、任务、渠道）处于禁用状态待审核。
🔴
需配置 needs_setup
缺少关键配置（API Key、认证），Agent 无法正常工作。
