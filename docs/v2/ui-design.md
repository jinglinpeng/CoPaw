## 设计原则

1. **风格一致**: 延续 Console 现有的 Ant Design 风格，主色 `#FF7F16`
2. **渐进式披露**: 默认展示最常用选项，高级选项折叠/可选
3. **安全优先**: 导出默认剥离 secrets，导入默认进入静默态，高危操作需硬性确认
4. **状态可见**: 通过标签、进度条、待办清单让用户始终了解当前状态
5. **功能闭环**: 每个操作链路（加密导出→加密导入、克隆→命名）都有完整的 UI 支撑

## 关键设计决策

### 导航位置：设置（Settings）分组

快照功能放在侧边栏**「设置」分组**下，而非「工作空间」下。

**理由：**
- 快照可以包含全局配置、多个工作空间，是**系统级功能**而非某个 Agent 独有
- 与同级的「Agent 管理」「模型」「环境变量」等设置项保持一致的抽象层级
- 列表页展示的是所有 Agent 的快照，不受当前选中 Agent 影响

**侧边栏位置：** 设置 → ... → 安全 → **快照** → Token 用量

**上下文弱化：** 进入快照页面后，侧边栏的 Agent 选择器降低透明度（`opacity: 0.45`），页面标题下方显示副标题"管理所有 Agent 的快照。与当前选中的 Agent 无关。"，避免用户误以为列表被当前 Agent 过滤。

### 快照范围：支持多工作空间选择

创建快照时，用户可以选择三种范围：

| 范围 | 说明 | 场景 |
|------|------|------|
| 当前 Agent | 仅快照侧边栏选中的工作空间 | 配置回滚、修改前备份 |
| 指定 Agent | 多选任意数量的工作空间 | 部分备份、相关 Agent 打包 |
| 所有 Agent | 全部工作空间 + 全局配置 | 定期全量备份、设备迁移 |

选择「指定 Agent」时**才**展开多选面板（渐进式披露），面板内含搜索框和已选摘要。

### 多 Agent 展示策略

解决 Agent 数量过多时的扩展性问题：

| 场景 | 展示方式 |
|------|----------|
| 列表页「包含 Agent」列 | 最多 2 个 chip + `+N` 徽章，hover 显示完整列表 |
| 全量快照 | 紫色标签「全部 Agent（N 个）」 |
| 恢复弹窗 | 摘要格式「共 N 个 Agent」 |
| 创建面板 | 带搜索的 checkbox 列表 + 底部「已选 N 个」 |

## 各页面设计要点

### 1. 快照列表页

- **面包屑**: 设置 / 快照
- **标题 + 副标题**: "快照管理" + "管理所有 Agent 的快照。与当前选中的 Agent 无关。"
- **侧边栏 Agent 选择器**: 降低透明度（dimmed），表明列表不受其过滤
- **顶部统计卡片**: 快照总数、总大小、最近快照时间
- **筛选栏**: 搜索框 + Agent 下拉筛选 + 内容类型筛选
- **表格列**: 勾选框、备注（含 ID）、包含 Agent（截断+N）、创建时间（可排序 ↓）、大小（可排序）、内容标签、操作
- **包含 Agent 列**: 最多 2 个 chip，超出显示 `+N` 徽章（hover tooltip 展示完整列表）
- **内容标签**: `工作空间`（蓝）、`密钥`（橙）、`全局`（灰）、`全部 Agent`（紫）
- **行操作**: 恢复、导出、更多菜单（⋯ → 删除快照）
- **删除**: 从垃圾桶图标改为下拉菜单中的文本项，点击后 Popconfirm 二次确认

### 2. 空状态

- 居中空状态图标 + 中文引导文案
- CTA 按钮「+ 创建第一个快照」
- Agent 选择器同样 dimmed

### 3. 创建快照 Modal

- **快照范围**: 三个 radio 选项（渐进式披露）
  - 当前 Agent（默认选中）
  - 选择指定 Agent → **仅此时展开**多选面板
  - 所有 Agent（全量备份）
- **多选面板**: 带搜索输入框的 checkbox 列表 + 底部「已选 N 个 · 预估 ~X MB」
- **预估大小**: info alert，随用户选择实时更新
- **备注输入框**: 可选
- **包含内容**: 工作空间数据（必选灰色）、密钥信息（默认选中）、全局配置
- **高级选项**: 折叠区域（排除对话历史、排除向量记忆），默认收起

### 4. 恢复确认 Modal

- **警告 alert**: 说明操作不可自动撤销，外部副作用不回滚
- **快照信息卡**: 包含备注、时间、版本、Agent 列表
- **恢复影响清单**: 列出将被替换的具体内容（配置、会话、技能、任务等），明示自动备份命名格式
- **恢复目标 Agent**: 下拉选择（多 Agent 快照时选择其中一个）
- **恢复模式**: 原地恢复 / 克隆为新 Agent
- **克隆输入**: 选择「克隆」后展开 Agent ID 输入框，提供默认命名预设，即时重名校验
- **操作护栏**: 底部 checkbox「我理解此操作将覆盖当前工作空间...」，未勾选时确认按钮置灰

### 5. 导出选项 Modal

- **默认安全**: info alert 说明默认剥离密钥
- **包含密钥**: 勾选后展开 YES 确认输入框，未输入 YES 时下载按钮置灰
- **加密选项**: 勾选后展开密码 + 确认密码输入框 + 警告"密码不会被保存"
- **密钥+加密联动**: 勾选包含密钥时自动勾选加密
- **输出文件名**: 预填充可编辑

### 6. 导入上传

- **4 步流程**: 上传 → 解密 → 验证 → 结果（非加密包跳过解密步骤）
- **拖拽上传区**: 点击或拖拽
- **安全提示**: 导入视为不可信来源，所有组件默认禁用

### 7. 导入解密（新增）

- **触发条件**: 上传文件后检测到加密包时进入
- **加密信息**: 显示文件名、大小、加密方式
- **密码输入**: 单个密码输入框 + 提示
- **多 Agent ID 映射**: 解析 manifest 后显示映射表（原 ID → 导入后 ID），冲突项自动重命名并高亮

### 8. 导入验证

- 居中进度条 + 当前步骤文字
- 显示文件名和 Agent 数量

### 9. 导入结果

- **统一状态**: 页面顶部、阶段 2 内部、侧边栏统一使用**最严重状态**
  - 有必须项 → `needs_setup`（红色）
  - 仅建议项 → `needs_review`（黄色）
- **汇总 alert**: "还需完成 N 个必须项后 Agent 才能正常运行"
- **两阶段反馈**: 文件导入 + 可运行性检查
- **待办清单**: 必须/建议，带「前往 →」快捷跳转
- **聊天测试按钮**: `needs_setup` 时置灰 + 提示"完成必须项后可用"

### 10. 导入失败（新增）

- **错误类型**: 校验失败 / 版本不兼容 / 资源超限 / 解密失败
- **错误详情**: 技术信息展示区（monospace 字体）
- **建议操作**: 引导用户重新下载、确认密码等
- **操作按钮**: 重新上传 / 返回列表

### 11. Agent 状态标签

| 状态 | 中文 | 颜色 | 含义 |
|------|------|------|------|
| `ready` | 就绪 | 绿色 | 所有组件正常运行 |
| `needs_review` | 待审核 | 黄色 | 可对话，但有组件待审核 |
| `needs_setup` | 需配置 | 红色 | 缺少关键配置 |

**状态唯一性规则**: 一个 Agent 在任意时刻只有一个状态，取最严重的。页面顶部标签、侧栏标签、Agent 管理表格共用同一套判定逻辑。

## 操作护栏设计

| 操作 | 护栏 |
|------|------|
| 恢复快照 | checkbox 确认 + 按钮置灰/激活 |
| 含密钥导出 | YES 输入确认 + 自动勾选加密 + 按钮置灰 |
| 删除快照 | 下拉菜单 → Popconfirm 二次确认 |
| 批量删除 | 二次确认弹窗 |
| 加密导出 | 密码 + 确认密码 + 不可恢复提示 |

## 设计系统 Token

| Token | 值 | 用途 |
|-------|------|------|
| `--primary` | `#FF7F16` | 主操作按钮、选中状态 |
| `--success` | `#52C41A` | 就绪状态、成功 |
| `--warning` | `#FAAD14` | 待审核、提醒 |
| `--error` | `#FF4D4F` | 需配置、危险操作 |
| `--border` | `#F0EDEB` | 边框、分割线 |
| `--sidebar-bg` | `#FAF7F5` | 侧边栏背景 |

## 路由规划

```
/snapshots              → 快照列表（设置分组）
/snapshots/import       → 导入流程（含解密、验证、结果步骤）
```

Modal 不需要独立路由（创建、恢复、导出、删除均为 Modal）。
