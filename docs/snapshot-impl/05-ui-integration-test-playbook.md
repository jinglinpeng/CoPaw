# Snapshot UI 集成测试剧本

> 目标：接手人按本剧本可完整验证“前端页面 + 后端接口”的联动是否可用。

## 0. 前置

- 后端运行：`127.0.0.1:8088`
- 前端运行：`http://localhost:5173`
- 打开页面：`http://localhost:5173/snapshot`

## 1. 入口与页面可达

1. 打开 Console 左侧 `设置`
2. 检查存在菜单项 `快照`（英文环境为 `Snapshot`）
3. 点击后 URL 变为 `/snapshot`
4. 页面标题应为“快照”/“Snapshot”

预期：

- 菜单可见
- 路由可达
- 无白屏/无 404

## 2. 创建快照

1. 点击“创建快照”
2. 选择范围：
   - `当前 Agent`
3. 填写备注（可选）
4. 提交

预期：

- 成功 toast（创建成功）
- 列表新增一条记录
- 记录包含：`snapshot_id`、创建时间、大小、内容标签

## 3. 列表与详情信息

检查列表列：

- 备注
- 包含 Agent（超过 2 个显示 `+N`）
- 创建时间
- 大小
- 内容标签（工作区/全局/密钥）

预期：

- 数据与后台返回一致
- 刷新页面后数据仍存在

## 4. 导出快照

1. 点击某条记录“导出”
2. 等待浏览器下载

预期：

- 下载触发
- 文件扩展名为 `.zip`
- 前端无报错

## 5. 恢复快照（原地恢复）

1. 点击“恢复”
2. 模式选“原地恢复”
3. 目标 Agent 选 `default`（或当前）
4. 确认提交

预期：

- 成功提示
- 后端日志可见 restore 相关流程
- Agent 可继续在 Console 使用

## 6. 恢复快照（克隆）

1. 点击“恢复”
2. 模式选“克隆为新 Agent”
3. 输入新 Agent ID（例如 `snapshot-exp`）
4. 确认提交

预期：

- 成功提示
- 新 Agent 出现在 Agent 管理列表
- 可切换到新 Agent

## 7. 导入快照（不可信路径）

1. 点击“导入”
2. 上传 zip
3. 可选输入 `agent_id`
4. 可选开启 `force`
5. 提交

预期：

- 返回 `ImportResult`
- 显示状态：`ready / needs_review / needs_setup`
- 显示 todo 清单
- skills/jobs/channels/mcp 已进入静默态（根据 summary/todo 体现）

## 8. 删除快照

1. 点击“删除”
2. 二次确认

预期：

- 成功提示
- 列表记录消失

## 9. 失败路径（必测）

- 上传非 zip 文件 -> 应提示错误
- 恢复不存在 snapshot_id -> 应提示失败
- 导入同名 agent 且未 force -> 应提示冲突
- 后端停止时访问 snapshot 页 -> 应提示接口失败，不应崩溃

## 10. 建议记录模板

每次测试记录：

- 用例编号
- 操作步骤
- 结果（Pass/Fail）
- 截图（可选）
- 对应网络请求与响应片段
- 关联日志（前端/后端）
